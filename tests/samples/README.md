# Test samples

**No malware is committed here, and none ever should be.**

## Why there is no `eicar.com` in this directory

The scaffold for this project reserved a slot for the EICAR test file. It is
deliberately not committed, and the test suite generates it at runtime
instead.

EICAR is not malware — it is a 68-byte string the industry agreed every
scanner should flag, so users can verify their tooling works. But every
real antivirus product detects it *by design*. Committing it means:

- Cloning the repository triggers the developer's antivirus.
- The file is quarantined or deleted before any test runs, and the failure
  that follows is confusing and looks like a bug in the scanner.
- On some configurations the whole working directory gets flagged.

So `tests/conftest.py` provides `eicar_bytes()`, which assembles the string
from parts at runtime, and an `eicar_file` fixture that writes it to
`tmp_path`. The fixture **skips the test** rather than failing if real-time
protection removes the file underneath it:

```python
def test_something(eicar_file):
    verdict = scanner.scan_file(eicar_file)
    assert verdict.is_threat
```

On Windows, exclude your pytest temp directory from Defender to run those
tests:

```powershell
Add-MpPreference -ExclusionPath $env:TEMP
```

CI does this automatically — see `.github/workflows/ci.yml`.

## Generating EICAR by hand

To verify an installed scanner outside the test suite:

```bash
python -c "print('X5O!P%@AP[4\\PZX54(P^)7CC)7}\$' + 'EICAR-STANDARD-ANTIVIRUS-TEST-FILE' + '!\$H+H*', end='')" > eicar.com
sentinel scan eicar.com
```

Expected: `EICAR-Test-File`, severity `medium`. Sentinel recognises it from
a built-in signature, so this works on a fresh install with no signature
download.

Its digests, for reference:

```
sha256  275a021bbfb6489e54d471899f7db9d1663fc695ec2fe2a2c4538aabf651fd0f
md5     44d88612fea8a8f36de82e1278abb02f
```

## Synthetic fixtures

Everything else the tests need is generated by fixtures in `conftest.py` —
none of it is real malware, all of it is built at runtime:

| Fixture | What it is |
|---|---|
| `clean_file` | Ordinary text |
| `powershell_dropper` | The download-and-execute pattern, in PowerShell |
| `ransomware_script` | A batch file deleting shadow copies |
| `fake_pe` | PE magic bytes under a `.pdf` name |
| `traversal_zip` | An archive whose member escapes with `../../` |
| `rtl_zip` | A member name using a right-to-left override |
| `corpus` | A directory mixing clean and malicious-looking files |
| `hash_signature_db` | A signature database you can add digests to |

These exercise the detectors without anything dangerous existing on disk.
If you need a new one, add a fixture — do not commit a sample.

## If you have a real sample to share

Do not put it here, and do not attach it to an issue or pull request. Open
an issue with the SHA-256 and a maintainer will arrange a private channel.
See `.github/SECURITY.md`.
